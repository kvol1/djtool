# Harmonic Mashup Telegram Mini App

Локальный Telegram Mini App для поиска гармонических сочетаний треков по колесу Camelot.

## Запуск

```bash
bun install
BOT_TOKEN=your_telegram_bot_token bun run dev
```

Скрипт сам запустит фронтенд, backend/bot и HTTPS-туннель. В консоли появится URL для BotFather.
